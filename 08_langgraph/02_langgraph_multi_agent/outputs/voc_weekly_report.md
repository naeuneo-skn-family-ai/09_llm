# 고객센터 주간 VOC 보고서

## 주간 운영 요약

전체 문의는 결제와 로그인 영역에 집중되었으며, 해결률은 양호한 수준이나 미해결 건과 SLA 초과 건이 남아 있어 우선 대응이 필요합니다. 특히 결제 오류와 배송 관련 정보 확인·변경 문제에 고우선순위 이슈가 집중되어 고객 불편과 만족도 저하로 이어질 위험이 확인되었습니다.

## 주요 VOC

### 미해결 사례

- `T004` 결제 · high: 모바일 결제 단계에서 반복 오류
- `T007` 배송 · high: 출고 완료 후 배송 위치 확인 불가
- `T011` 배송 · medium: 배송지 변경 요청이 주문에 반영되지 않음

### 분석 결과

- 결제 문의가 가장 많았고, 모바일 결제 단계에서 반복 오류가 발생해 결제 과정의 안정성 점검이 필요합니다.
- 로그인 문의도 높은 비중을 차지해 인증 및 접근 과정에서 반복되는 불편이 있는지 추가 확인이 필요합니다.
- 배송 관련 미해결 사례가 두 건 확인되었으며, 출고 후 위치 확인 불가와 배송지 변경 미반영 등 배송 정보 연동 및 변경 처리 문제가 두드러졌습니다.

## 권장 조치

- 모바일 결제 오류의 재현 조건과 발생 구간을 점검하고, 원인 분석 및 재발 방지 조치를 우선 추진합니다.
- 출고 이후 배송 위치 정보 연동과 배송지 변경 반영 절차를 확인하고, 관련 부서 및 물류 시스템 간 처리 상태를 점검합니다.
- 고우선순위 미해결 건과 SLA 초과 건을 우선 모니터링하며, 담당자별 후속 일정과 고객 안내를 명확히 관리합니다.
